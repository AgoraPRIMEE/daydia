# Feliz Cumpleaños - Página Web

Página web de felicitacion de cumpleanos con diseño en negro, rosa y naranja.

## Estructura del proyecto

```
daydedia/
├── index.html      # Pagina principal
├── mascota.jpeg    # Foto de la mascota
└── README.md       # Este archivo
```

## Caracteristicas

- Pagina de bienvenida con tipografia cursiva elegante
- Texto en naranja claro legible y comodo (#ffb347, #ffd1a4)
- Carta estilo carta real con forma y silueta de carta
- Papel carta con renglones y borde doblado
- Tipografia handwriting (Dancing Script, Caveat, Great Vibes)
- Paleta de colores negro, rosa y naranja
- Boton Siguiente grande
- IP del servidor con especificacion del launcher oficial y version 26.3
- Al copiar, toda la tarjeta desaparece completamente
- Ramo de flores animado que crece desde abajo
- Las flores se superponen a todo el contenido (z-index 9999)
- Flores con efecto 3D (sombras, gradientes, bordes)
- Lazo rosa decorativo en el centro del ramo
- 6 tipos diferentes de flores rosas
- Tallos verdes con hojas
- Crecimiento fluido y natural
- Funciona directamente en el navegador

## Servidor Minecraft

IP: `DaydeDia.aternos.me`

Entrar desde el launcher oficial, version 26.3
